# B - Jhankar's Programming Journey

## 📝 Problem Statement

Jhankar is learning programming at Phitron. He has a list of `N` programming topics arranged in the order he studies them. Each topic has a difficulty level.

Jhankar starts learning from the first topic. He continues to the next topic only if its difficulty level is strictly greater than the current topic's difficulty level.

If the next topic has an equal or lower difficulty level, Jhankar stops learning.

Your task is to print the difficulty level of the last topic Jhankar reaches.

## 📌 Constraints

- \\(1 \le N \le 100\\)
- \\(1 \le A_i \le 10^9\\)
- All input values are integers.


## ⌨️ Input Format

- The first line contains an integer `N`, the number of programming topics.
- The second line contains `N` integers, `A1, A2, ..., AN`, representing the difficulty levels of the topics in order.

## 🖥️ Output Format

Print a single integer representing the difficulty level of the last topic Jhankar reaches.

## 📥 Sample Input 1

```
5
1 5 10 4 2
```

## 📤 Sample Output 1

```
10
```

## 💡 Sample Explanation 1

Jhankar starts with a topic of difficulty `1`. The next topics have difficulty `5` and `10`, so he continues learning.

The following topic has difficulty `4`, which is less than `10`. Therefore, he stops at difficulty level `10`.

## 💻 C Solution — Jhankar's Programming Journey

```

#include <stdio.h>

int main()
{
    int N;
    scanf("%d", &N);

    int A[100];

    for (int i = 0; i < N; i++)
    {
        scanf("%d", &A[i]);
    }

    int current = A[0];

    for (int i = 1; i < N; i++)
    {
        if (A[i] > current)
        {
            current = A[i];
        }
        else
        {
            break;
        }
    }

    printf("%d\n", current);

    return 0;
}

```

## 💡 Solution Hints

1. Take input `N` and store the topic difficulty levels in an array.
2. Initialize `current` with the first topic's difficulty.
3. Use a `for` loop to check each next topic.
4. If `A[i] > current`, update `current`; otherwise, stop the loop using `break`.
5. Print `current`, the difficulty level where Jhankar stops.

Concepts: Array, `for` loop, `if-else`, and `break`.
